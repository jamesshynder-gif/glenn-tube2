# Glenn Tube

A slick orange-and-black YouTube-clone style frontend with:

- Email sign in / account creation flow (browser localStorage demo)
- Homepage slogan: **"The more sus the better."**
- Like button and comments section
- Lightweight AI-style video idea generator

## Run locally

Open `index.html` directly in your browser.

## Notes

This is a frontend prototype and does not include a backend or real authentication provider.
